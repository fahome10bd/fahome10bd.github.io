# Authoring by Research Track

This directory is organized into 4 research track folders matching your portfolio:

1. `1_Computer_Vision_and_Deep_Learning/`
2. `2_Photogrammetry_and_3D_Reconstruction/`
3. `3_GIS_and_Remote_Sensing/`
4. `4_Signal_Processing_and_Biomedical_Systems/`

## How to add or edit project content:
- Inside each track folder, each project has a `.docx` document named after the project.
- You can edit any existing file or add a new `.doc` / `.docx` file in the corresponding track folder.
- Each document contains:
  1. **Metadata header**: Title, Summary, Context, Role, Order, Featured.
  2. **Problem Description & Context**: Clear problem definition and project background.
  3. **Technical Challenges & Approaches**: Methodology, algorithms, architectures.
  4. **System Architecture & Visual Diagrams**: Placeholders for architectural flowcharts and diagrams.
  5. **Effects & Quantitative Results**: Measured outcomes, metrics, benchmark accuracies.
  6. **Conclusion & Key Takeaways**: Lessons learned, academic insights, technical understandings.
