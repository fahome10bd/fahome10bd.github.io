At HawarIT Limited, I led the development of point cloud intelligence algorithms for semantic segmentation and automated Building Information Modeling (BIM) extraction from large-scale LiDAR datasets.

### Technical Implementation & Impact
- **Multi-Source LiDAR Processing:** Built processing pipelines handling dense 3D point clouds across diverse acquisition platforms: aerial surveys, mobile vehicle-mounted mapping systems, and high-precision indoor laser scanners.
- **Automated Pipe & Geometry Extraction:** Implemented custom algorithms to detect industrial and building piping networks, segment structural components, and extract geometric properties directly from unstructured 3D point data.
- **Quantitative Results:** Achieved **95% extraction accuracy** while cutting manual 3D modeling and processing time by **60%**.
